# @reticlehq/protocol

Shared wire contract for [Reticle](https://github.com/reticlehq/reticle): constants, TypeScript types, and zod schemas for every message that crosses the browser ↔ bridge ↔ agent boundary.

You usually don't install this directly — it's a deprecated alias of [`@reticlehq/core`](https://www.npmjs.com/package/@reticlehq/core); import from `@reticlehq/core` in new code. Apache-2.0.
